## 新增

- 【技術債・低】Sass `@import` 棄用警告：Bootstrap 5.3 的 SCSS 仍用 `@import`，`pnpm build` 會印大量 Sass deprecation 警告。等 Bootstrap 改用 `@use` 後升級，或在 vite 的 `css.preprocessorOptions.scss` 設 `silenceDeprecations: ['import']`（屬 A1 的設定檔，需另開任務）。
- 【技術債・低】TypeScript 釘在 `~6.0.3`：vue-tsc 3.3.13 與 TS 7 不相容（`typescript/lib/tsc` 未匯出）。vue-tsc 支援 TS 7 後升級 TypeScript，改 `package.json` 與 lockfile。
- 【流程・中】`allowBuilds` 的 `core-js` 核准是為了讓 install 不報錯；若之後想收緊，可改成明確拒絕 `core-js`（`core-js: false`）並確認 `--frozen-lockfile` 仍能通過。

## 結案

- R1：專案骨架與測試骨架已由 A1 建立（package.json scripts、vue-tsc、Vitest + @vue/test-utils 冒煙測試、wrangler.jsonc、`.dev.vars` 入 `.gitignore`），DoD 三條指令可執行。
