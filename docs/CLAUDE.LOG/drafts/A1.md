## 2026-10-24 Prime Trail 專案骨架與共用型別（spec：docs/superpowers/specs/2026-10-24-prime-trail-design.md）

- **起因**：GAME-2 / plan Task A1。repo 還沒有任何程式碼，DoD 三條指令不存在；後層任務都依賴同一份套件、設定與 `core/types.ts`，所以由 A1 一次放好。
- **裁定（使用者）**：無。
- **做法**：依 plan 逐字建立 scripts、設定檔、型別、`geometry`／`primes`／`rng`、fixture、router 與空 view。依賴一次裝齊並鎖進 `pnpm-lock.yaml`，後層不再動 `package.json`。`package.json` 加 `packageManager: pnpm@12.3.4` 鎖版；部署 script 名為 `deploy`，一律以 `pnpm run deploy` 呼叫。
  - TypeScript 釘在 `~6.0.3`，不用 latest 的 7.0.2：vue-tsc 3.3.13 在 TS 7 下會因 `typescript/lib/tsc` 不在 package exports 而直接崩潰，`pnpm typecheck` 跑不起來。等 vue-tsc 支援 TS 7 再升。
  - build script 核准：pnpm 12 預設擋掉依賴的 postinstall，`pnpm install` 會以 `ERR_PNPM_IGNORED_BUILDS` 失敗。用 `pnpm approve-builds --all` 寫入 `pnpm-workspace.yaml` 的 `allowBuilds`，允許 `esbuild`、`workerd`、`@parcel/watcher`、`core-js`。前三者是原生二進位或平台套件所需；`core-js` 的 postinstall 只印訊息，是為了讓 `--frozen-lockfile` 不再報錯。（`onlyBuiltDependencies` 在此版 pnpm 不被採用。）
  - fixture 數值照抄 plan；僅把原註解中的 CJK 改成英文，因為之後的結構測試禁止 `.ts` 含 CJK 字元。
  - `main.scss` 依 plan 只匯入指定的 Bootstrap 部件，Bootstrap JS 不載入。
- **守門**：測試檔 0 -> 5，案例 0 -> 29（geometry、primes、rng、fixture、smoke）。TDD：先跑確認 5 個檔因模組不存在而失敗，實作後全綠。fixture 的斷言（Hamiltonian、灰底集合、ALT 路徑僅索引 11–17 不同）與 plan 數值一致，沒有差異。DoD `typecheck`、`test`、`build` 全過。
- **流程**：單 agent 在獨立 worktree（分支 `task/GAME-2`）執行，基底 e21a792。
- **踩坑**：（1）TS 7 與 vue-tsc 不相容，見上。（2）pnpm 12 對 build script 預設拒絕，且第一次 `pnpm add` 就會報錯但套件其實已寫入 `package.json`，需補 approve 再 install。（3）Bootstrap 5.3 仍用 Sass `@import`，build 會印大量 deprecation 警告（不影響結果）。
- **遺留**：見 `docs/backlog/drafts/A1.md`。
