# Prime Trail SEO／GEO meta 與 OG 形象圖

- 狀態：**定稿**（使用者 2026-10-25 確認，含規劃者決定）
- 日期：2026-10-25
- 上位文件：`docs/superpowers/specs/2026-10-24-prime-trail-design.md`（主 spec）§1.2 目標、§1.4 反目標（不用 Hidato／Numbrix 等商標）

## 1. 為什麼

正式站 `https://game-prime-trail.jyyan.info/` 的 `index.html` 只有 `<title>Prime Trail</title>`，沒有 description、OG、結構化資料。分享到 LINE／Facebook／X／Discord 時沒有預覽圖與說明；搜尋引擎與 AI 搜尋（GEO）拿不到「這是什麼遊戲、怎麼玩、免費」的可引用文字。

## 2. 範疇

只動靜態資產，不改 Vue 程式：

| 檔案 | 內容 |
|---|---|
| `index.html` | title、description、canonical、robots、Open Graph、Twitter Card、JSON-LD |
| `public/og-image.jpg` | 1200×630 OG 形象圖（codex 產圖，風格沿用 `public/illustrations/hero.webp`），約 155 KB |
| `public/robots.txt` | 全站允許，指向 sitemap |
| `public/sitemap.xml` | 只列首頁 `/` |
| `public/llms.txt` | GEO：給 AI 爬蟲的純文字簡介（是什麼、規則、難度、功能、網址） |

## 3. 文案（zh-TW）

- `<title>`：`Prime Trail｜質數小路：1 到 100 一筆連線的數字益智遊戲`
- description：`從龍頭出發，沿上下左右把 1 到 100 連成一條不重複的路，質數只能落在黃色質數格。1000 道固定題目、三種難度，免費、免註冊，手機與電腦都能玩，還能匯出 PDF 列印。`
- OG／Twitter：`og:type=website`、`og:site_name=Prime Trail`、`og:locale=zh_TW`、`og:title`／`og:description` 同上、`og:image` 絕對網址 `https://game-prime-trail.jyyan.info/og-image.jpg`（含 width/height/alt）；`twitter:card=summary_large_image`。
- JSON-LD：`@type: ["VideoGame","WebApplication"]`，name、description、url、image、inLanguage `zh-TW`、genre `Puzzle`、applicationCategory `GameApplication`、operatingSystem `Any`、`offers.price 0`、`isAccessibleForFree true`、`numberOfPlayers 1`。

## 4. 規劃者決定（可推翻）

- **canonical 固定指向首頁**：SPA 只有一份 `index.html`，`/play/<id>/<難度>` 共 3000 個網址內容相近；全部歸併到首頁，避免稀薄重複頁。代價是題目頁不會各自被索引（v1 本來就不需要）。
- **sitemap 只列首頁**，理由同上。
- 「質數小路」作為中文副名只出現在 title／description，不改 UI 內的 `app.title`。
- OG 圖用 JPEG（相容 LINE／舊 Facebook 爬蟲，WebP 不保險），不放中文字（AI 產圖中文易錯字），只放 `Prime Trail` 與 `1 → 100`。

## 5. 不做

- 不做每頁動態 meta（需 SSR 或 Worker 改寫 HTML，v1 純靜態）。
- 不做英文版 meta／hreflang（主 spec 尚無 en）。
- 不送 Google Search Console／Bing 驗證（需人操作）。

## 6. 驗收

- DoD：`pnpm typecheck`、`pnpm test`、`pnpm build` 全綠；`dist/` 內含 `og-image.jpg`、`robots.txt`、`sitemap.xml`、`llms.txt`。
- 新增 `src/__tests__/index-meta.test.ts`：讀 `index.html` 斷言 description、`og:image`（絕對網址）、`twitter:card`、可解析的 JSON-LD 存在，且全文不含 Hidato／Numbrix（反目標守門）。
- 部署後人工：用 Facebook Sharing Debugger／opengraph.xyz 看預覽。
